# Base64 Auto Decoder

어느 사이트에서든 base64로 인코딩된 내용을 찾아, 원문은 그대로 둔 채 해당 문단 아래에
디코딩 결과를 보여주는 유저스크립트입니다. 결과가 링크면 클릭 한 번으로 이동합니다.

## 설치

1. [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
2. [`base64-autodecoder.user.js`](https://github.com/akshwpsh/base64-autodecoder/raw/master/base64-autodecoder.user.js)를 엽니다. Tampermonkey가 설치 화면을 띄웁니다.

## 동작 방식

- **링크 확정**: 디코딩 결과에 `http://`, `https://`, `magnet:?`가 나오면 확정으로 보고 바로 펼칩니다. 최대 3겹 중첩까지 따라갑니다.
- **추정**: 링크는 아니지만 읽을 수 있는 글로 풀리는 경우입니다. 원문에 🔓 배지만 붙이고, 눌러야 펼칩니다.
  메뉴에서 「추정 결과도 바로 펼치기」를 켜면 배지 없이 자동으로 펼칩니다.
- 원문은 절대 지우거나 바꾸지 않습니다. 밑줄만 긋습니다.
- `<wbr>`, `<mark>`, 문법 강조 `<span>`으로 쪼개진 토큰, 줄바꿈이 낀 토큰도 잡습니다.
- 드래그해서 선택한 문자열도 디코딩합니다.

## 메뉴

Tampermonkey 아이콘을 누르면 나옵니다.

- 추정 탐지 켜기/끄기
- 추정 결과도 바로 펼치기
- 이 사이트에서 끄기 / 끈 사이트 목록 관리
- 기본값으로 되돌리기

## 확인

`test/cases.html`을 브라우저로 열면 까다로운 상황을 모아 둔 케이스 페이지가 나옵니다.
각 칸의 「기대」와 실제 동작을 대조하면 됩니다.
